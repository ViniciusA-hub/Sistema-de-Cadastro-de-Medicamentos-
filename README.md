# Sistema-de-Cadastro-de-Medicamentos-
É um sistema simples usado para cadastrar remedios de uma farmácia

Os dados permanecem salvos em um arquivo CSV, permitindo que sejam recuperados quando o programa for aberto novamente.

## Funcionalidades

- Cadastro de medicamentos
- Listagem de medicamentos
- Busca por nome
- Salvamento automático dos dados ao sair

## Como executar

1. Abra a pasta do projeto.
2. Execute:

```
python main.py
```

## Requisitos técnicos aplicados

- Menu com if/elif/else
- Estrutura de repetição while
- Funções com parâmetros e retorno
- Lista de dicionários
- Persistência em arquivo CSV
- Uso apenas da biblioteca padrão do Python
